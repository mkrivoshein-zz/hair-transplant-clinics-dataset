# Hair transplant clinics: Google ratings in 12 cities

A hand-checked list of 327 hair transplant providers in 12 medical tourism destinations, with their Google Maps rating, review count, provider type and website age. Collected for [GraftAtlas](https://graftatlas.com/), an independent hair transplant clinic directory.

Analysis of this data: [Google ratings barely separate hair transplant clinics](https://graftatlas.com/research/google-ratings/). In short, 237 of the 320 rated providers (74%) are rated 4.8 or higher, and only 5 are below 4.0.

## Columns

| Column | Meaning |
|---|---|
| `city`, `country` | Destination |
| `name` | Name as shown on Google Maps |
| `type` | Clinic, agency (sells surgery done in partner clinics), aesthetics / med spa, or mostly non-surgical. Based on the provider's own website and Google category |
| `google_rating`, `google_reviews` | Google Maps rating and number of reviews on the collection date. Empty if Google shows no rating |
| `collected` | Collection dates |
| `website_domain` | The provider's website domain |
| `domain_registered_year` | Registration year of that domain in public WHOIS records |
| `claimed_founded_year` | Founding year the provider claims (website, directories). Not verified |
| `founded_earliest` | The earlier of the two years above |
| `graftatlas_url` | Provider page on graftatlas.com |

## How the list was built

Each city list comes from Google Maps searches in English and the local language ("hair transplant", "hair restoration clinic", "trasplante capilar" and so on). Every provider that does hair, beard or eyebrow transplants and has a website is kept. Salons, wig shops, pure cosmetology and listings without an address are left out. Being on the list is not a recommendation, and no provider pays to be included.
